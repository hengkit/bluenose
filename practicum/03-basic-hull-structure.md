## Purpose

Stage 3 is short, but it is important: correct construction defects before the model is mounted and before detailed fittings are installed.

## 1. Inspect for starved glue joints

Run a bright light across the hull and inspect:

- keel joints;
- plank seams;
- stern/transom joints;
- deck joints;
- bulwark structure.

A starved joint is one where the adhesive did not fully bridge the joint.

## 2. Fill defects

For small defects, use wood glue or the model spackling/filler specified by the manual.

1. Clean the defect.
2. Work adhesive/filler into the joint.
3. Allow it to cure fully.
4. Sand flush.

Do not use filler to correct incorrect hull geometry.

## 3. Smooth the hull, bulwarks and deck

1. Start with a suitable sanding block.
2. Work with the hull's designed curves.
3. Avoid rounding sharp structural edges.
4. Check with a batten.
5. Remove dust before finishing.

## 4. Waterline and finish preparation

Use the plans and manual painting section to establish the waterline and finish scheme.
