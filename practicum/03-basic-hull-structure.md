## Bench standard

**Identify → measure from plan → dry-fit → inspect → glue → cure → inspect again.**

If a measurement or fitting location in this practicum differs from the plans, **the plans win**.

---

## Stage 3 workflow

The manual treats this as its own stage. Read the complete Stage 3 section before committing to final sanding or bottom finishing.

### Hull inspection

- [ ] Stem/keel transition fair.
- [ ] Sternpost/keel transition fair.
- [ ] Plank surface fair.
- [ ] No accidental flats.
- [ ] No structural gaps.

### Final hull fairing

1. Mark high spots lightly.
2. Use a long sanding block.
3. Follow the hull's designed curvature.
4. Preserve the keel/stem/stern edges.
5. Check under raking light.
6. Clean the hull before finishing.

### Bottom/finish work

Follow the manual's Stage 3 treatment and the color/finish guidance in the preliminary painting section.

- [ ] Waterline reference established from the plans.
- [ ] Required bottom treatment complete.
- [ ] Finish does not interfere with later adhesive joints.
- [ ] Hull symmetry rechecked.

### Stage 3 quality gate

- [ ] Basic hull structure complete.
- [ ] Hull lines match the plans.
- [ ] Required bottom treatment complete.
- [ ] Model ready for Stage 4 mounting.
