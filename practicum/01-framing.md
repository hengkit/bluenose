# Model Shipways MS2130 Bluenose — Part 1 — Framing the Plank-on-Bulkhead Hull

**Kit:** MS2130 Bluenose Canadian Fishing Schooner  
**Scale:** 1:64  
**Manual stage:** Stage 1

Build the complete structural hull framework, from the center keel through the deck beams, before starting Stage 2 planking.

## Bench standard

**Identify → measure from plan → dry-fit → inspect → glue → cure → inspect again.**

If a measurement or fitting location in this practicum differs from the plans, **the plans win**.

## 1. Bending Wood

**Parts/materials:** curved wood called out by the manual and plans.

1. Test the bending method on scrap.
2. Pre-bend gradually rather than forcing the finished piece.
3. Allow the wood to stabilize.
4. Compare the curve with the plan.
5. Do not glue a piece that is fighting the hull shape.

- [ ] Curve agrees with plan.
- [ ] No split/crushed grain.
- [ ] Part sits naturally.

## 2. Center Keel Assembly

1. Mark the reference line and bulkhead stations on both sides as instructed.
2. Dry-fit the laser-cut keel pieces.
3. Check the assembly on a flat building board.
4. Glue the joints without introducing a twist.
5. Sight along the keel from both ends.
6. Let it cure completely before proceeding.

- [ ] Straight.
- [ ] No twist.
- [ ] Station marks retained.
- [ ] Mast openings correct.

## 3. Installing the Sternpost

1. Dry-fit the sternpost.
2. Check its relationship to the keel and plan profile.
3. Glue while holding it square.
4. Recheck after cure.

## 4. Cutting the Rabbet

1. Transfer the rabbet location from the plan.
2. Make shallow cuts first.
3. Remove material gradually.
4. Test-fit scrap plank stock.
5. Refine until the plank lands cleanly.

**Do not deepen the rabbet to compensate for a badly shaped plank.**

## 5. Tapering the Stem

1. Mark the taper from the plan.
2. Remove material symmetrically.
3. Use a sanding block for the long transition.
4. Preserve the rabbet.
5. Compare frequently with the plan.

## 6. Installing the Bulkheads

1. Identify each bulkhead before removing it from its sheet.
2. Dry-fit every bulkhead before gluing any.
3. Check the bearding line and centerline relationship shown in the manual.
4. Check that the bulkhead is perpendicular to the keel.
5. Check the deck edge against adjacent bulkheads.
6. Correct fit before applying adhesive.
7. Glue progressively.
8. Recheck while the adhesive is workable.

## 7–9. Stern Blocks, Horn Timbers & Mast Slots

- [ ] Dry-fit stern blocks/transom framing.
- [ ] Check centerline and stern profile.
- [ ] Install horn timbers.
- [ ] Install the specified mast-slot covering pieces.
- [ ] Confirm the mast openings remain usable.

## 10. Waterway

1. Dry-fit around the deck edge.
2. Pre-bend difficult curves.
3. Install in manageable sections.
4. Keep the edge fair.
5. Remove squeeze-out.

## 11. Knightheads & Hawse Timbers

- [ ] Locate from the plan.
- [ ] Dry-fit both sides.
- [ ] Check bow symmetry.
- [ ] Preserve hawse openings.
- [ ] Install.

## 12–14. Main Rail, Buffalo Rail and Stanchions

1. Pre-bend rail stock.
2. Dry-fit the complete run.
3. Check sheer before gluing.
4. Install the main rail.
5. Install buffalo rail/monkey board/monkey rail.
6. Mark and install remaining bulwark stanchions.
7. Compare port and starboard.

- [ ] Check deck geometry.
- [ ] Glue.
- [ ] Recheck after cure.
