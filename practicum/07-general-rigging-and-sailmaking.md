## Bench standard

**Identify → measure from plan → dry-fit → inspect → glue → cure → inspect again.**

If a measurement or fitting location in this practicum differs from the plans, **the plans win**.

## 1. Rigging Options

- [ ] Decide full sails / partial sails / furled / no sails.
- [ ] Decide which lines will remain visible.
- [ ] Plan installation order before permanent attachment.

## 2. Rigging Plans

Use **Sheet 5** for the rigging profile and **Sheet 6** for rigging details/belaying information.

1. Trace every line from source to destination.
2. Mark every block/deadeye.
3. Mark belaying points.
4. Identify lines that must be installed before access is blocked.

## 4. Treating the Lines

- [ ] Test the manual's treatment method on scrap.
- [ ] Treat standing line consistently.
- [ ] Treat running line consistently.
- [ ] Avoid making line unnaturally stiff.

## 5. Belaying Lines

The manual uses the rigging details/belaying information to establish where lines terminate.

- [ ] Match line identity to its destination.
- [ ] Practice the required knot/seizing.
- [ ] Keep tails to scale.
- [ ] Do not let lines cross unrelated fittings.

## 6. Rigging Tools

Prepare:

- [ ] Fine scissors
- [ ] Tweezers
- [ ] Fine needle/rigging tool
- [ ] Small pliers
- [ ] Magnification
- [ ] Line treatment
- [ ] Fine cutting tools

## 7. Blocks and Deadeyes

- [ ] Clean holes.
- [ ] Verify sizes.
- [ ] Prepare stropping.
- [ ] Match deadeye pairs.
- [ ] Orient holes consistently.
- [ ] Prepare lanyards.

## 8. Sailmaking

- [ ] Identify each sail.
- [ ] Transfer outline from the plans.
- [ ] Cut accurately.
- [ ] Add hems/seams/details required by the manual.
- [ ] Mark attachment points.
- [ ] Test-fit before final attachment.

## 9. Rigging Without Sails

If omitting sails:

- [ ] Install the rigging the manual calls for in the no-sail configuration.
- [ ] Keep unused attachment points neat.
- [ ] Do not omit structural standing rigging merely because sails are omitted.

## Stage 7 quality gate

- [ ] Rigging plans understood.
- [ ] Line inventory complete.
- [ ] Blocks/deadeyes prepared.
- [ ] Belaying points identified.
- [ ] Sails prepared or configuration intentionally selected.
