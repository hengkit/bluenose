## Reference philosophy

Every stage gives **both references equally**:

- **Manual:** stage + page range + figure guidance
- **Plans:** sheet(s) to have on the bench
- **Parts:** identify the physical component before cutting/gluing
- **Procedure:** moderate-detail numbered steps
- **Quality gate:** checks before advancing

The official manual's table of contents confirms the Stage 1 and Stage 2 operation sequence, including deck planking in Stage 2. citeturn1view2

## Important

Exact dimensions, part numbers, fitting locations, line diameters and rigging paths should always be taken from the actual plan sheets/manual. This practicum is intentionally **not** a substitute for those drawings.
