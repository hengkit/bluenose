# Manual Alignment

This edition deliberately uses **nine Markdown files for nine manual stages**.

The Model Shipways Bluenose manual's table of contents lists Stages 1–9 and their operation names. 

The manual also identifies the six plan sheets as:
1. Laser-Cut Wood Patterns
2. Plank-On-Bulkhead Hull Construction
3. Hull Plan and Profiles
4. Hull and Spar Details
5. Rigging Profile
6. Rigging Details

The six-sheet plan set is also sold separately as MSPL2130.

## Design rule

Where the manual and plans give an exact measurement or location, the practicum points you back to that source rather than inventing a value.
